## Featured Project

### AI Home Care Service & Incident Management System

一套行動優先的居家照護服務紀錄與異常管理系統，整合服務紀錄管理、AI 摘要、異常判斷及 LINE 即時通知。

A mobile-first home-care management system integrating service records, AI-generated summaries, incident detection, and LINE notifications.

**Key features**

- 個案與居家照護服務紀錄管理
- Gemini API 自動產生照護紀錄摘要
- 跌倒及異常描述自動判斷
- LINE Messaging API 即時通知
- n8n 自動化工作流程
- Docker Compose 整合開發環境

**Technology stack**

`Flutter` · `FlutterFlow` · `NocoBase` · `n8n` · `Docker` · `PostgreSQL` · `Gemini API` · `LINE Messaging API`
